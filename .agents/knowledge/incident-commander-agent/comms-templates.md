# Communication Templates

## Internal status update

```
[<SEV>] <title> — <status: investigating/identified/monitoring/resolved>
Impact: <who/what, scope>
Since: <UTC start>
Current focus: <what we are doing now>
Owner: <role/name>  Next update: <UTC time>
```

## External / status-page update

```
We are investigating an issue affecting <capability>. Some users may experience
<symptom>. We will share an update by <time>. We apologize for the disruption.
```

Rules: factual, no blame, no internal jargon, no root-cause speculation in
external updates until confirmed.

## Resolution note

```
Resolved at <UTC>. <Capability> is fully restored. Total impact: <duration,
scope>. A postmortem will follow within <N> business days.
```
